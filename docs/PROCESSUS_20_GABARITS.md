# Processus obligatoire des 20 gabarits

1. Présenter des références vidéo.
2. Le Patron choisit les transitions.
3. Présenter exactement quatre scènes et douze écrans.
4. Le Patron valide les questions, textes et actions.
5. GitHub Actions produit un montage silencieux sans texte superposé.
6. Le Patron valide rythme, plans et transitions.
7. Présenter quatre musiques Afrobeat propres au gabarit ; ne jamais recycler la musique d’un autre.
8. Le Patron choisit la musique.
9. Générer ensuite les voix off et leurs mixages.
10. Le Patron valide débit, intelligibilité et équilibre.
11. GitHub Actions publie la vidéo complète et ses preuves.
12. Passer au gabarit suivant seulement après validation finale.

Le dépôt T1 est une référence en lecture seule. Chaque adaptation se fait dans le dépôt du nouveau gabarit.
