# Rushes de démonstration — sources et licence

## Règle de distribution

Les quatre fichiers stock bruts sont téléchargés localement par `tools/fetch_rushes.py` dans `rushes/cache/`, dossier ignoré par Git. Ils ne sont pas publiés comme fichiers stock autonomes. Seul le montage transformé T2 est distribué.

## Limite sémantique

Ces rushes n’ont pas été tournés comme une même recette. Ils servent uniquement à juger le moteur, le rythme, l’habillage et les transitions. Une validation de production devra utiliser les quatre prises cohérentes d’un même commerçant.
